# ThermaLift

ThermaLift is an engineering project developed through the **EPICS (Engineering Projects in Community Service) program at Arizona State University**.

The project focuses on designing a temperature-controlled cargo attachment for a drone-based delivery system. ThermaLift is intended to safely transport time-sensitive and temperature-sensitive payloads, including medications, vaccines, food, and other items.

The system is designed to actively heat and cool its cargo while maintaining a desired internal temperature during transport.

## Project Objectives

- Design a lightweight, structurally capable cargo enclosure
- Monitor internal temperature using multiple sensors
- Implement active heating and cooling
- Develop Raspberry Pi/Linux-based monitoring and control software
- Maintain a desired internal temperature during transport
- Collect thermal data for testing and system validation
- Minimize weight and power consumption for drone integration

## Current Development

The project is currently in the prototyping and development phase. Current work includes temperature sensing, thermal testing, control-system development, enclosure design, and evaluation of heating and cooling methods.

## Software Platform

ThermaLift's monitoring and control software is being developed for a **Raspberry Pi running Linux**, with support for interfacing with temperature sensors and future thermal-control hardware.
